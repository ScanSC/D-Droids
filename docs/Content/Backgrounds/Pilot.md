# Background: Pilot
*From speeders to space cruisers, you know exactly how to pilot them, provided you have enough arms to do so.*

**Skill Proficiencies**: Perception, Science\
**Tool Proficiencies**: Any vehicle\
**Languages**: -\
**Equipment**: A lucky charm you hang in the cockpit, a set of pilot clothes with helmet and glasses, and a pouch containing 15 credits

### Driving style
Choose which skill will be used when you drive a vehicle between Intelligence, Wisdom, and Charisma.
